## Technical Overview

I am a **Systems Architect and Software Engineer** specializing in **backend infrastructure, agentic AI systems, Model Context Protocol (MCP) tooling, and full-stack software development**. My focus is writing clean, performant code, engineering low-latency APIs, and deploying scalable distributed systems.

### Core Engineering Focus
* **Systems & Backend:** Designing microservice architectures, asynchronous pipelines, and REST/gRPC APIs using Python (FastAPI/Django) and Node.js.
* **AI Engine & Tools:** Building autonomous LLM agentic workflows, custom MCP tools, vector databases, and retrieval pipelines.
* **Software Architecture:** Clean code design patterns, modular codebases, state management, and continuous development practices.
* **Secondary / Operations Skills:** Technical leadership, operational logistics, and social tech platform deployment.
