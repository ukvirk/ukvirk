## Technical Profile

I am a **Systems Architect and Software Engineer** focused on low-level programming, backend microservices, distributed system mechanics, and autonomous agent integration. My core technical work centers on writing clean, modular code, engineering scalable APIs, and building server implementations using Model Context Protocol (MCP).

Outside of core engineering, I apply software architectures to optimize real-world economic and operational workflows.

### Core Technical Focus
* **Backend Systems:** High-performance RESTful APIs, database schema design, queue management, and asynchronous task processing.
* **Agentic AI & Protocol Engineering:** Custom MCP servers, tool-calling pipelines, subagent orchestration, and prompt-driven execution engines.
* **Software Design:** OOP principles, memory-efficient data structures, algorithm optimization, and clean microservices architecture.
